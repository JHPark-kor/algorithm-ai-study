아래 PDF 제출물에서 추출한 논문 리뷰 텍스트를 읽고 GitHub README에 들어갈 짧은 요약 정보를 작성한다.

작성 원칙:

- 문체는 설명형 대화체가 아니라 논문 개요/초록 문체로 작성한다.
- "본 논문은 ...을 목적으로 한다", "연구에서는 ...를 비교하였다", "실험 결과 ...가 확인되었다"와 같은 문장을 사용한다.
- PDF 텍스트에 없는 정보는 추측하지 말고 "확인 필요"라고 적는다.
- 팀원의 표현을 그대로 길게 복사하지 말고, 핵심 의미만 요약한다.
- SVM과 어떤 관련이 있는지 반드시 드러낸다.
- README에 바로 붙일 수 있도록 작성자당 3~5줄 안에 들어가게 작성한다.
- 불필요한 안내문, 피드백 문구, 확인 요청 문구는 쓰지 않는다.
- 각 항목은 길어도 한 문장으로 작성한다.
- PDF 텍스트 추출 과정에서 문장이 깨져 있더라도, 확인 가능한 내용만 사용한다.

출력 항목:

- paper_source: 논문 출처. 저자, 연도, 제목, 학회/저널이 보이면 포함한다.
- keywords: 주요 키워드 4~6개.
- overview: 논문이 다루는 문제와 목적을 한 문장으로 요약한다.
- data: 데이터 설명을 한 문장으로 요약한다.
- method: 적용 방법론을 한 문장으로 요약한다.
- result: 주요 결과를 한 문장으로 요약한다.
- project_idea: 3주차 미니 프로젝트로 이어질 수 있는 아이디어를 한 문장으로 요약한다.
